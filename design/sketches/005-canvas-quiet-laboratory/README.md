## Variant: Canvas · Quiet Laboratory

### Design stance
The canvas as *instrument*: cool slate neutrals, analytical blue, dense mono metadata.
Observability is quiet — data does the talking, the chrome says little.

### Key choices
- Layout: open canvas, same typed-artifact engine; nodes are flat, left-border typed, filename-titled
- Typography: sans weight-600 titles + mono metadata; no serif warmth
- Color: `#0f1215` canvas, `#eef0ec` paper, slate `#1e262d` chrome, blue `#5f9ac0` accent
- Interaction: identical mechanics (drag, ports, inspector, lenses, zoom)

### Trade-offs
- Strong at: academic/measurement feel; maximum neutrality for long analytical days
- Weak at: zero warmth; risks reading as "yet another data tool"

### Best for
- If the owner's heart lives in the Academic vertical more than Substack
