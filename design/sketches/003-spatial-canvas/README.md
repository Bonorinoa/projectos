## Variant: Spatial Canvas

### Design stance
Your projects are *placed*, not listed: the canvas is memory. Layout is user-owned — the "fully customizable canvas" from the original pitch, kept quiet and dark so the cream plates carry the light.

### Key choices
- Layout: free canvas, draggable plates (position persisted), zoom +/−
- Typography: serif plate titles, mono tags
- Color: near-black green canvas + grid, cream plates `#e8e2d4`, moss focus outline, coral live-dot
- Interaction: drag to arrange, double-click opens drawer with the live receipt, zoom controls

### Trade-offs
- Strong at: spatial memory, ownership, delight — feels like a place, not a file listing
- Weak at: discoverability (new projects hide), accessibility (spatial layout must keep its list/timeline equivalents per the brief), state management cost

### Best for
- The Instrumented-Atelier ideal of a *workshop*; users who think in arrangement. Riskier to build well — layout persistence, zoom, and list-equivalence are all real work.
