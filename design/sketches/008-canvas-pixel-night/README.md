## Variant: Canvas · Pixel Night

### Design stance
The same Synodos language inverted: a night workshop. Deep teal-black field,
cream cards, gold/rust signals, hard black offset shadows. Pixel-art sprites glow
against the dark; the studio at 2am.

### Key choices
- Field: `#121a18` with cream 4.5% pixel dither; panel `#1a2422`; line `#3a4a45`
- Cards: sand `#ece5d8` with 1px black border and `4px 4px 0` near-black shadow
- Signals: gold `#cfa35a` (badges, connectors, active lens), rust `#c4694a`
- Type: Space Mono chrome + labels; Geist-class sans for card titles
- Same 12×12 crispEdges sprites; gold dashed connectors; square controls with
  hard shadow presses (translate on :active)

### Trade-offs
- Strong at: focus, contrast, "instrument" character; sprite colour has more
  punch on dark; closer to the earlier Atelier mood the owner liked structurally
- Weak at: dark chrome is heavy in daylight; cream cards on dark invert the
  Synodos proportions (their cards are dark-on-light)

### Best for
- If the product should feel like a tool you sit *inside*, not a page you read
