How live status stays honest

This page can scan a selected ProjectOS folder while it remains open. It counts code and test files, recognizes expected implementation surfaces, and refreshes every 20 seconds when the browser grants a persistent folder handle.

A filename is weak evidence, so the scanner only labels it detected. Implementation and verification come from projectos-roadmap-status.json, written later by development agents or CI and backed by evidence paths.

{
  "updatedAt": "ISO timestamp",
  "commit": "git commit or tree identifier",
  "tasks": {
    "m0.shell": {
      "status": "verified",
      "evidence": ["evidence/gates/gate-a/report.json"]
    },
    "m0.graph": {
      "status": "blocked",
      "note": "Candidate failed packaging gate"
    }
  }
}

Allowed states are planned, detected, implemented, verified, and blocked. The dashboard never executes tests or modifies the codebase. Manual acceptance checkboxes live only in this browser.
